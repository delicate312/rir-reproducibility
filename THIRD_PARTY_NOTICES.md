# Third-party components

`experiments/ego_immune_recognition/riskbench_metadata/vendor_social_gan/models.py` and `losses.py` are the project’s existing vendored Social-GAN implementation from the RiskBench baseline repository. Their local README describes device-compatibility changes. The MIT license with copyright (c) 2018 Agrim Gupta, Justin Johnson is retained next to those files.

Other third-party libraries are declared in `requirements.txt` and installed separately. No pretrained third-party weights or external datasets are included. No blanket license is added to original author code without an author choice.
